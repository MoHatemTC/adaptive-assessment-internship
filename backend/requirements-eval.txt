# Offline evaluation harness only (backend/evaluation). NOT a runtime dependency of the
# engine or of the Streamlit app, and deliberately kept out of requirements.txt so that
# neither deployment installs it.
#
# Two reasons that separation is load-bearing:
#   - streamlit/requirements.txt has to mirror every runtime backend dependency, because
#     Streamlit Cloud installs only that one file. Anything listed as runtime is shipped.
#   - the judged-metric layer (deepeval, added in the DeepEval stage) makes billed model
#     calls. A package that cannot be imported cannot be invoked by accident.
#
# Install with:  pip install -r requirements.txt -r requirements-eval.txt

-r requirements.txt

# within-candidate error correlation `r`.
scipy>=1.11,<2

# that silently changes shape makes two runs incomparable without saying so.
#
# Install into a SEPARATE environment, never the one that runs pytest:
